# Directorio de Agentes (.agents)

Este directorio centraliza las instrucciones, el contexto y las habilidades para los agentes de IA que operan en este repositorio.

## Contenido

- `AGENTS.md`: Guía general de comportamiento y contexto del proyecto.
- `skills.md`: Catálogo de habilidades de ingeniería y observabilidad (Caveman).

## Uso

Cualquier agente que trabaje en este proyecto debe:
1. Leer los archivos en este directorio para entender el flujo de trabajo.
2. Utilizar el comando `caveman` para todas las operaciones de terminal.
3. Respetar las reglas de observabilidad y ahorro de tokens.
